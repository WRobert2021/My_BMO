# iMessage Relay Issue Records

Use this directory for relay issues that need more detail than the continuation
summary in `AGENT_README.md`. Every detailed issue must also be linked from that
summary.

An issue record should include:

- classification: active blocker, non-blocking defect, technical debt,
  environment limitation, unresolved database behavior, or future enhancement;
- severity and stage discovered;
- a privacy-safe reproduction;
- observed behavior and current theory;
- workaround, if any;
- whether it blocks the next stage; and
- resolution evidence when closed.

Do not include private message text, handles, attachment filenames, secrets, or
credentials.
